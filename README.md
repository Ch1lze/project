# Система анализа дорожно-транспортных происшествий

## О проекте

Система анализа ДТП — учебный веб-проект для загрузки, просмотра и анализа статистических данных о дорожно-транспортных происшествиях.

Приложение разрабатывается на Python с использованием Streamlit и Pandas.

## Цель проекта

Упростить анализ статистики ДТП, сделать данные более наглядными и помочь пользователю выявлять закономерности в имеющейся информации.

## Основные функции

- Загрузка данных из файлов CSV и Excel.
- Предварительный просмотр загруженных данных в таблице.
- Фильтрация по регионам и годам.
- Расчёт основных статистических показателей.
- Построение графиков для визуального анализа.
- Обработка ошибок загрузки и чтения файлов.

Перечисленные функции представляют общий план развития системы. Их наличие в текущей версии необходимо проверять отдельно.

## Что реализовано сейчас

- Загрузка файлов CSV и Excel (`.xlsx`, `.xls`).
- Чтение CSV с автоматическим определением разделителя и поддержкой кодировки Windows-1251.
- Отображение количества строк и столбцов загруженного файла.
- Предварительный просмотр первых 100 строк.
- Вывод сообщений при успешной загрузке и при ошибках чтения.

Фильтрация, расчёт статистических показателей и построение графиков относятся к дальнейшим этапам разработки.

## Установка и запуск

Для запуска требуется установленный Python и доступ к командной строке.

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Запустите приложение:

```bash
streamlit run src/app.py
```

После запуска откройте адрес, который отобразит Streamlit в терминале.

## Критерии готовности

Проект считается готовым к сдаче, когда:

- приложение запускается без критических ошибок;
- загрузка поддерживаемых файлов работает корректно;
- данные отображаются в таблице;
- фильтрация по регионам и годам работает правильно;
- статистические показатели рассчитываются корректно;
- графики соответствуют используемым данным;
- пустые и некорректные входные данные обрабатываются понятным для пользователя образом;
- документация по запуску и использованию актуальна;
- основные функции проверены, а критические ошибки исправлены.

Проект находится в активной разработке. Требования и критерии готовности уточняются по мере реализации системы.
