# Система анализа дорожно-транспортных происшествий

## О проекте

Система анализа ДТП — учебное веб-приложение для загрузки, просмотра и последующего анализа статистических данных о дорожно-транспортных происшествиях.

Проект разрабатывается на Python с использованием Streamlit и Pandas.

## Цель проекта

Упростить анализ статистики ДТП, сделать данные нагляднее и помочь пользователям сравнивать показатели и выявлять закономерности.

## Реализованные функции

- Загрузка файлов CSV и Excel (`.xlsx`, `.xls`).
- Автоматическое определение разделителя в CSV.
- Поддержка кодировки Windows-1251 для CSV.
- Отображение количества строк и столбцов загруженного файла.
- Предварительный просмотр первых 100 строк.
- Вывод сообщений об успешной загрузке, пустом файле и ошибках чтения.

## Планируемые функции

- Проверка структуры и содержимого данных.
- Фильтрация по регионам и годам.
- Расчёт статистических показателей.
- Построение графиков.
- Обновление результатов после изменения фильтров.

Планируемые функции будут реализовываться по мере развития проекта.

## Технологии

- **Python** — язык программирования.
- **Streamlit** — веб-интерфейс.
- **Pandas** — чтение и обработка табличных данных.
- **openpyxl** — чтение файлов Excel.
- **Git и GitHub** — контроль версий и совместная работа.

## Установка и запуск

### Требования

Для запуска необходим установленный Python и доступ к командной строке.

### Установка зависимостей

Выполните команды из корневой папки проекта:

```bash
pip install -r requirements.txt
```

### Запуск приложения

```bash
streamlit run src/app.py
```

После запуска откройте адрес, который Streamlit выведет в терминале.
