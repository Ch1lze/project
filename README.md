# Система анализа дорожно-транспортных происшествий

## О проекте

Система анализа ДТП — учебный веб-проект для обработки и визуального анализа статистических данных о дорожно-транспортных происшествиях.

Приложение позволит загружать данные из файлов CSV и Excel, просматривать их в таблице, фильтровать по регионам и годам, рассчитывать основные статистические показатели и строить графики.

## Цель проекта

Упростить анализ статистики ДТП, сделать данные более наглядными и помочь пользователю выявлять закономерности в имеющейся информации.

## Основные функции

- Загрузка данных о ДТП из файлов CSV и Excel.
- Отображение данных в таблице.
- Фильтрация по регионам и годам.
- Расчёт основных статистических показателей.
- Построение графиков для визуального анализа.
- Просмотр результатов анализа в удобном интерфейсе.

## Технологии

- Python — язык программирования.
- Pandas — обработка табличных данных.
- Streamlit — создание веб-интерфейса.
- Plotly — построение графиков.
- Git и GitHub — управление версиями и хранение проекта.
